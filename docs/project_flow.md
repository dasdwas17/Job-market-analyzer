# 招聘市场数据分析系统 - 项目流程设计方案

## 1. 项目概述

### 1.1 项目目标

爬取 BOSS直聘、拉勾网、看准网 三大招聘平台的"数据分析师"相关岗位信息，进行多维度分析并生成可视化看板，最终输出求职策略建议。

### 1.2 核心指标

| 指标 | 目标值 |
|-----|-------|
| 数据量 | 5000+ 条有效岗位记录 |
| 覆盖城市 | 19个（4个一线城市 + 15个新一线城市） |
| 关键词 | 4个（数据分析师、数据运营、商业分析、数据产品经理） |
| 数据源 | 3个（BOSS直聘、拉勾网、看准网） |

### 1.3 分析维度

| 维度 | 分析内容 |
|-----|---------|
| 薪资分析 | 按城市/学历/经验/公司类型/行业分布 |
| 技能分析 | 技能词云、需求频次TOP20、技能共现网络 |
| 竞争度分析 | 城市岗位数量 vs 平均薪资四象限分析 |
| 公司画像 | 行业分布、规模分布、薪资水平 |

### 4.2 爬取流程（单城市单关键词）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 爬取流程 (SpiderManager.crawl())                                            │
│                                                                             │
│ 1. 记录 batch_start_time = datetime.now()                                   │
│ 2. 遍历城市列表 (19个城市)                                                   │
│    └── 遍历关键词列表 (4个关键词)                                            │
│        └── spider.crawl(keyword, city, max_pages)                          │
│            ├── 打开搜索页面                                                 │
│            ├── 等待页面加载 (WebDriverWait)                                  │
│            ├── 解析岗位列表 (BeautifulSoup)                                 │
│            ├── 遍历每条岗位                                                 │
│            │   ├── 提取基础信息 (名称/薪资/城市/公司)                         │
│            │   ├── 提取经验/学历/技能标签                                    │
│            │   ├── 解析薪资字符串 → salary_min/max/median                  │
│            │   ├── 生成 job_id = MD5(source+url+company_name)              │
│            │   ├── 生成 company_id = MD5(source+company_name+url)          │
│            │   ├── upsert_company(company_data)                            │
│            │   ├── upsert_job(job_data, skills)                            │
│            │   └── delay(5-10秒)                                           │
│            ├── 翻页                                                         │
│            └── 循环直到 max_pages 或无更多数据                               │
│ 3. mark_inactive_jobs(source, batch_start_time)                            │
│ 4. 输出统计信息                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.3 反爬策略

| 反爬手段 | 实现方式 | 代码位置 |
|---------|---------|---------|
| **User-Agent轮换** | 仅用于API请求，维护10+个桌面UA | `utils/user_agent.py` |
| **IP策略** | 不使用数据中心代理，控制频率（5-10秒/次），避开高峰时段 | `config/settings.py` REQUEST_DELAY |
| **验证码处理** | Selenium检测到验证码 → 暂停 + 蜂鸣提示 + 人工介入 | `spiders/boss_spider.py` handle_captcha() |
| **动态渲染** | WebDriverWait显式等待关键元素加载 | `spiders/base_spider.py` |
| **请求头伪装** | 完整浏览器请求头（Accept/Referer/Cookie等） | `utils/user_agent.py` get_headers() |

## 5. 数据清洗流程（Phase 2）

### 5.1 清洗流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 数据清洗流程 (DataCleaner.clean())                                          │
│                                                                             │
│ 1. 从数据库读取原始数据                                                      │
│    SELECT * FROM jobs WHERE is_active=1                                      │
│                                                                             │
│ 2. 薪资解析 (parse_salary)                                                  │
│    "15-25K·14薪" → {min: 15000, max: 25000, median: 20000, months: 14}      │
│                                                                             │
│ 3. 技能提取 (extract_skills + segment_text)                                 │
│    job_description → 使用jieba分词 + 自定义词典匹配技能                       │
│                                                                             │
│ 4. 标准化处理                                                               │
│    - experience: "3年经验" → "3-5年"                                        │
│    - education: "本科及以上" → "本科"                                        │
│    - company_size: "100-299人" → "100-499人"                                │
│                                                                             │
│ 5. 去重                                                                     │
│    按 (company_name + job_name + city) 去重                                 │
│                                                                             │
│ 6. 异常值处理                                                               │
│    - salary_min > salary_max → 置为NULL                                     │
│    - 薪资 < 1000 或 > 500000 → 置为NULL                                     │
│    - 空值填充                                                               │
│                                                                             │
│ 7. 更新数据库                                                               │
│    UPDATE jobs SET ... WHERE id=?                                           │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 薪资解析规则

| 输入格式 | 解析结果 | 示例 |
|---------|---------|------|
| `15-25K` | min=15000, max=25000, median=20000, months=12 | "15-25K" |
| `15-25K·14薪` | min=15000, max=25000, median=20000, months=14 | "15-25K·14薪" |
| `20K` | min=20000, max=20000, median=20000, months=12 | "20K" |
| `10-20万/年` | min=8333, max=16667, median=12500, months=12 | "10-20万/年" |
| `15000-25000元/月` | min=15000, max=25000, median=20000, months=12 | "15000-25000元/月" |

### 5.3 技能提取规则

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 技能提取流程                                                                │
│                                                                             │
│ 1. 加载自定义技能词典 (SKILL_KEYWORDS)                                      │
│    包含52个预定义技能，覆盖9个分类                                           │
│                                                                             │
│ 2. 对 job_description + skill_tags 进行 jieba 分词                          │
│    segment_text(text) → 过滤停用词 → 保留长度≥2的词                          │

│    extract_skills(text, SKILL_KEYWORDS) → 返回匹配的技能列表                 │

│ 4. 去重合并                                                                 │
│    合并列表页技能标签和描述中提取的技能，去重                                 │
│                                                                             │
│ 5. 更新 job_skills 表                                                       │
│    删除旧记录 → 批量插入新记录                                               │
```

### 6.2 分析指标定义

| 指标 | 计算公式 | 用途 |
|-----|---------|-----|
| **薪资中位数** | (salary_min + salary_max) / 2 | 衡量薪资水平 |
| **年薪中位数** | salary_median × salary_months | 衡量年度收入 |
| **薪资成本比** | salary_median / LIVING_COST_INDEX | 衡量城市性价比 |
| **技能频次** | COUNT(skill_name) / COUNT(job_id) | 衡量技能需求度 |
| **竞争指数** | 岗位数量 / 平均薪资 | 衡量求职难度 |

### 6.3 求职策略生成逻辑

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 求职策略生成流程                                                            │
│                                                                             │
│ 1. 筛选高薪岗位 (Top 25%)                                                   │
│    high_salary_jobs = df[df.salary_median >= df.salary_median.quantile(0.75)]│
│                                                                             │
│ 2. 分析高薪岗位技能组合                                                      │
│    - 统计高薪岗位中技能出现频次                                              │
│    - 与普通岗位对比，找出差异技能                                            │
│    - 构建"高薪技能组合"推荐列表                                              │
│                                                                             │
│ 3. 城市性价比分析                                                           │
│    - 计算各城市 salary_cost_ratio = median / living_cost_index               │
│    - 排序并推荐性价比最高的城市                                              │
│                                                                             │
```

## 11. 执行命令

### 11.1 项目入口

```bash
# 初始化数据库
python main.py init

# 爬取数据 (全部来源)
python main.py crawl --source all --keyword "数据分析师" --city "北京" --pages 10

# 爬取数据 (仅BOSS直聘)
python main.py crawl --source boss --keyword "数据分析师" --city "北京" --pages 10

# 执行数据清洗
python main.py clean

# 执行数据分析
python main.py analyze

# 启动可视化仪表盘
python main.py dashboard

# 导出Tableau数据
python main.py export --format csv --output output/tableau_export.csv
```

### 11.2 独立模块运行

```bash
# 单独运行数据库测试
python test_db.py

# 单独运行爬虫
python -m spiders.spider_manager

# 单独运行清洗
python -m analysis.data_cleaning

# 单独运行分析
python -m analysis.job_strategy

# 单独启动仪表盘
streamlit run visualization/dashboard.py
```
